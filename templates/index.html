Ekstensi Browser (Manifest V3)

Dapat dipasang di Google Chrome, Brave Browser, Microsoft Edge, Opera, dan browser berbasis Chromium lainnya.

Cara Pasang (Hanya 1 Menit):

  1. Buka chrome://extensions di browser.
  2. Aktifkan sakelar Developer Mode di kanan atas.
  3. Klik tombol Load unpacked.
  4. Pilih folder extension dari proyek ini:
.../youtube_to_mp3/extension
